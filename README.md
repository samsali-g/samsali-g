### Browser-First Web Tools

Independent static web utilities built to run client-side — no file uploads, no accounts, no tracking.

**Projects**

- [ExifStudio](https://www.exifstudio.online) — browser-local EXIF/IPTC/XMP metadata editor, C2PA provenance & shutter-count inspector, GPS geotagger, PDF metadata cleaner, 300 DPI & HEIC tools.
- [Alfalaki](https://alfalaki.space) — real-time astronomy & ephemeris observatory: interactive star map, natal & synastry wheels, moon phases, lunar months, eclipses (EN / AR / FR).
- [WedMaroc](https://www.wedmaroc.com) — Moroccan wedding budget calculator & vendor pricing reference across 28 cities (AR / FR / EN).
